In this report, we will describe a mixed technique for finding causal relations, using the combination of probability trees and PC (Peter-Clark) algorithm. Probability trees provide a straightforward, top-down representation of conditional probabilities, and the PC algorithm extracts causal connections automatically from data using conditional independence tests. Based on a health dataset, we illustrate how combined use of these two techniques provides richer and more easily understood causal data. The combined solution can help determine directionality of relationships found in probability trees and give statistically stable causal graphs. Scalability and complexity have not been addressed yet, but the combined approach has potential applications in medical diagnosis, economics, and beyond.
